# Catalyst：从科学知识网络中寻找尚未建立的联系

**Literature-Based Discovery · Temporal Knowledge Graphs · Scientific Hypothesis Generation**

[English](README.md) · **简体中文**

> 一个尚未完成的科研探索：利用科学概念网络的历史演化，寻找已有知识之间尚未被明确建立、但可能值得进一步研究的联系。

这个项目不是为了提出一种新的图神经网络算法，也不是要自动证明科学假设。它最初的目标更直接：**科学文献中是否存在大量尚未被充分连接的知识？能否利用网络结构与历史演化，提前找到其中一些值得研究的关联？**

项目已实现多种文献网络构建、图特征计算、神经排序模型与训练流程，但尚未得到可靠的端到端科学发现结果。由于数据质量、图稀疏性和研究时间成本，工作目前暂时搁置。

---

## 1. 研究动机：科学知识中的低垂果实

### 1.1 鱼油与雷诺综合征：尚未被发现的公共知识

这个项目最初受到 Don R. Swanson 于1986年发表的论文 [*Fish Oil, Raynaud's Syndrome, and Undiscovered Public Knowledge*](https://pubmed.ncbi.nlm.nih.gov/3797213/) 启发。雷诺综合征是一种涉及末梢血液循环异常的疾病，患者可能因寒冷或情绪刺激出现手指、脚趾血流受限。Swanson 注意到，当时存在两组相对独立的医学文献：

- 一组研究鱼油，报告了其对血液黏度、血小板聚集和血管反应性的影响。
- 另一组研究雷诺综合征，发现这些生理因素与疾病症状之间存在联系。

如果把两组知识放在一起，就可能得到一个值得进一步检验的假设：**鱼油是否可能缓解雷诺综合征？**

![鱼油与雷诺综合征的 A–B–C 文献推理：通过血液黏度、血小板聚集和血管反应性连接两组文献；虚线表示待检验假设。](assets/fish-oil-raynaud.zh-CN.svg)

*Swanson（1986）的文献推理示意。实线表示文献中已有的联系，虚线表示由此提出的假设；这不是本项目的实验结果，也不表示已证实治疗效果。*

这个例子吸引我的地方，不只是它提出了一个新的医学假设，而是提出了一种不同于传统检索的知识发现方式。已有的知识并不一定缺少。真正缺少的，可能只是将它们联系起来的人。传统文献检索通常从已知问题出发，寻找相关证据。但研究者首先需要知道应该搜索什么。如果两个研究领域长期缺乏交流，即使相关论文都已公开，也未必有人意识到它们可以组合起来。这让我开始思考：如果不依赖研究者事先提出明确的问题，而是从整个科学知识网络出发，是否能够主动找到类似的潜在联系？

### 1.2 雪球地球：不同学科可能握着同一问题的不同部分

另一个启发来自雪球地球（Snowball Earth）。新元古代地层中存在一些长期难以解释的地质现象，例如低纬度冰川沉积证据，以及冰川沉积结束后紧接着出现的盖帽碳酸盐岩。与此同时，气候动力学研究已经揭示了冰—反照率正反馈的可能性：冰雪覆盖增加会使地球反射更多太阳辐射，导致进一步降温，极端情况下可能进入全球冻结状态。然而，全球冻结又产生新的困难：如果地球被冰雪覆盖，为什么后来还能够重新变暖？

在[1992年的雪球地球构想](https://authors.library.caltech.edu/records/vaysf-cca32)中，Joseph Kirschvink 将这些地质证据与一种脱离全球冰冻的机制联系起来：全球冰冻会强烈抑制消耗大气二氧化碳的化学风化过程，但火山活动仍然能够持续向大气释放二氧化碳。经过漫长积累，温室效应可能最终使地球脱离冰冻状态。这一思路进一步将地质沉积、古地磁、气候动力学、大气温室效应和长期碳循环联系起来。

Paul Hoffman 在[2009年的回顾](https://doi.org/10.1111/j.1365-2451.2009.00716.x)中指出，在20世纪80年代末以前，研究元古代冰川沉积的地质学家与研究极端冰冻状态的气候动力学家之间，存在明显的信息隔阂：一方掌握了地质证据，另一方拥有能够解释这些现象的理论工具，却没有充分认识到彼此成果之间的联系。这并不意味着雪球地球的所有争论都已经解决，也不意味着一个算法能够直接发现完整的雪球地球理论。但它体现了我特别感兴趣的现象：

**一个学科长期困扰的问题，其答案的一部分可能已经存在于另一个学科中，只是尚未被充分联系起来。**

我把这些潜在机会理解为科学知识中的“低垂果实”。它们不一定是全新的自然规律，也可能是现有知识的重新组合、一个旧问题的重新解释，或者一条值得进一步检验的研究线索。

### 1.3 从文献检索转向主动发现

我希望探索一种不同的研究入口：不是先提出假设，再寻找文献支持；而是先分析文献之间的知识结构，**识别尚未被明确建立、但可能正在形成的关联**，再交由研究者或 AI 科学家系统继续推理和验证。最终希望得到的不是一句“模型发现了某种科学规律”，而是一组有明确来源、能够回溯文献、值得进一步调查的候选科学关系。

## 2. 核心设计理念：网络结构可能比语义相似度更值得关注

### 2.1 为什么不直接使用语义向量预测关联？

这是项目最初一个重要的设计判断。科学概念的命名、分类及其文字描述，往往已经包含既有学科的知识组织方式。例如，不同专业术语通常存在某种层级关系：一个概念属于哪个学科、哪个分支、与哪些概念在定义上接近。这些信息本身已经反映了当前的知识分类体系。因此，我担心直接依赖语义相似度，会在一定程度上重复这种分类体系的判断。尤其对于跨学科知识发现，这可能存在一个矛盾：

**我们希望找到的恰恰是那些在现有学科分类中相距较远、但在科学机制上可能存在联系的概念。**

两个概念的名称非常相似，不代表它们的结合具有很高的研究价值；反过来，两个语义相距很远的概念，也可能通过一系列间接机制产生重要联系。如果模型主要依据语义预测，可能更擅长找到那些已经符合现有知识分类习惯的关联，却不一定擅长寻找跨越既有分类边界的联系。所以，项目从一开始就希望把重点放在**关系如何形成，而不只是概念如何被描述**。这并不是说语义信息完全无用。实际代码中也引入了 SciBERT 预训练向量。但在我的原始构想里，语义应当是辅助信息，网络拓扑及其时序演化才是主要研究对象。

### 2.2 科学概念网络可以看作一个不断演化的系统

最初的设想是利用 OpenAlex 的论文、引文关系、发表时间和概念标签，抽象出随时间演化的科学概念网络。其中，以论文为主要载体：如果两个概念共同出现在符合条件的论文中，就可以建立概念之间的共现关系。引文网络则提供论文之间的关系背景，并用于部分早期研究路径。在历史时点 $t$，构建当时可观察到的概念关系图：

$$
G_t=(V,E_t)
$$

对于两个尚未存在直接连接的概念 $u,v$，希望根据历史网络判断：

$$
P\big((u,v)\in E_{t+\Delta t}\mid G_{\leq t}\big)
$$

这里最初关注的是历史 BFS 距离大于1的概念对，尤其是已经存在间接路径、却还没有共同建立直接关系的概念。一种帮助我理解这个过程的直觉，是把不同概念群体想象成正在演化的星系。两个星系是否接近，不只取决于它们当前的距离，还与周围的结构、相互作用和运动状态有关。类似地，两个概念未来能否形成联系，也可能受到共同邻居、局部社区、枢纽节点以及邻域变化趋势的共同影响。这只是启发式类比，不表示科学知识网络真的遵循某种引力定律。但它引出了一个具体问题：

**两个概念在尚未直接连接之前，它们周围的网络结构是否已经出现某些可以识别的变化？**

## 3. 特征设计与研究思路

项目尝试从不同角度描述两个概念之间的关系。

| 特征 | 设计动机 |
|---|---|
| BFS 距离 | 当前关系的最短拓扑距离 |
| 双向 PPR 类传播量 | 两个概念在全局网络中的相对位置与可达性 |
| Ego-graph | 各自局部邻域的结构与组织方式 |
| 共同邻居数量 | 两个概念已有多少间接连接 |
| 共同邻居的度分布 | 桥接它们的是广泛连接的枢纽概念，还是较具体的概念 |
| Adamic–Adar | 降低高连接度共同邻居的权重 |
| 聚类系数 | 局部邻域内部的连接紧密程度 |
| 社区归属（设想） | 判断概念是否位于同一知识社区 |
| 共同邻域的时序变化（设想） | 观察两组概念的局部关系是否正在逐渐接近 |
| SciBERT | 提供概念文本的语义表示；已定位的编码脚本使用概念名称 |

其中，BFS、传播量、共同邻居、Adamic–Adar、局部子图以及部分结构统计已经体现在不同版本的代码中。社区归属和连续时序变化属于设计中考虑的方向，并未形成统一、经过验证的完整实现。另一个重点是**如何处理枢纽节点（hub）**。例如，两个很具体的科学概念可能都与“气候变化”相关，但这条间接联系未必包含足够具体的研究信息。相比之下，通过一个连接范围较小、但机制关联更明确的中间概念建立联系，可能更值得调查。后期代码尝试对高连接度节点施加路径代价：

$$
c(u,v)=\log\left(\frac{\deg(u)+\deg(v)}{2}+1\right)
$$

并结合 Adamic–Adar、低度共同邻居等结构特征，减少泛化枢纽对候选关系判断的影响。这些特征的意义首先在于表达研究思路，而不是预先断言它们一定能够提高预测表现。

## 4. 代码实现与方法演化

这是一个经过多次尝试、不断调整任务和模型的研究项目，并不存在一个从开始就确定不变的最终算法。

### 4.1 从论文引用到概念关系

早期工作尝试将推荐模型和链接预测方法迁移到科学论文网络，使用论文引用、语义表示和候选排序来识别潜在关系。随后，研究重点逐渐转向时间演化的概念共现网络，并尝试使用历史图距离变化构造预测目标。最终，v15 路线进一步引入局部子图、结构特征与多路表示融合。主要代码包括：

- [论文引用与早期模型](research/citation/)
- [时序概念图构建](research/temporal/build_temporal_data.py)
- [时序特征预计算](research/temporal/precompute_v15.py)
- [v15 模型与训练](research/temporal/train_temporal_v15.py)
- [后续修复版本](research/temporal/fixes/)

### 4.2 神经模型的实现

后期 v15 使用 PyTorch 实现了三个表示分支：

| 分支 | 主要输入 | 功能 |
|---|---|---|
| PairMLP | 21维显式图特征 | 学习节点对之间的结构关系 |
| PENCIL 风格的 Transformer | 局部子图结构与预计算语义表示 | 编码概念邻域及候选上下文 |
| SubgraphGNN | 两个端点及其合并子图 | 建模候选关系周围的图连接 |

三个分支的表示进一步融合，输出候选关系的排序分数。这里的目标并不是证明复杂模型一定优于简单方法，而是在实际探索过程中尝试表达不同尺度的网络信息。相关实现保留了原始研究路径，也注明了对既有推荐模型、图学习方法和第三方代码的借鉴。

### 4.3 训练与历史实验

研究中尝试过不同的监督与排序方法，包括分类、成对排序、BPR、基于距离变化的排序，以及结合 NDCG 权重的排序损失。实际效果并不理想，也没有形成一个可以支持稳定科学发现能力的统一结果。时序实验涉及多个历史窗口，覆盖2005—2024年的部分数据。仓库保留了候选构建、模型训练、评测流程及历史记录。需要区分的是，不同版本曾使用不同的预测目标。例如，后期 v15 主要学习未来加权距离对应的相关性等级，并不直接等于最初设想的“预测首次出现的概念连接”。

这些版本作为研究演化过程予以保留，不将它们的指标合并为同一种任务的最终成绩。

## 5. 为什么项目暂时停止？

项目最终暂停，并不是因为缺少继续尝试模型的想法，而是逐渐遇到了几个更基础的问题。

### 5.1 概念图过于稀疏

在限定学科、概念层级和历史窗口后，图中的许多概念缺少足够的有效连接。尤其是希望预测未来首次形成的跨领域关系时，真正符合目标的正样本相对稀少，而候选空间又很大。这使得训练信号有限，也增加了构造合理候选集和监督目标的难度。我尝试调整过多个损失函数和排序策略，但没有得到足够理想、稳定的结果。继续增加模型复杂度，也未能从根本上解决这个问题。

### 5.2 OpenAlex 概念标签的噪声比预期严重

这是最终决定暂停的主要原因。项目使用的是 OpenAlex 旧版 Concepts 体系。它提供了较大规模的科学概念分类，但实际使用中逐渐发现，概念标签和论文归属并不总是可靠。例如，我曾在人工排查时遇到疑似涉及 `Lightning` 的概念混淆：气象学中的闪电与苹果设备的 Lightning 接口可能被错误关联到不同语义的标签。这个具体案例仍需回溯原始概念 ID 和论文记录确认。类似问题会直接影响网络构建。

如果同一个科学概念在不同论文中被标成不同节点，或者一个词在不同学科中的含义被混淆，那么图上的连接状态就可能不再对应真实的科学文献关系。

**最麻烦的情况是：两个概念在相关文献中事实上已经建立过联系，但由于概念识别或映射错误，构建出的网络却显示它们从未连接。**

对于一个专门预测“首次连接”的系统来说，这不只是普通的数据噪声，而是会直接影响任务标签是否成立。而且，模型越复杂，不代表它越能自动纠正这种问题。它也可能只是在学习错误概念网络中的统计规律。OpenAlex 后来也[停止维护旧版 Concepts，转而使用 Topics](https://help.openalex.org/data/concepts/)。官方说明提到了旧体系的准确性与维护问题；这与项目中遇到的数据质量困难相呼应，但不能代替对具体错误记录的核查。

### 5.3 历史代码与研究目标也存在一些偏差

由于项目经历了较多版本迭代，部分实现出现过候选索引、节点对应、子图填充和排序计算方面的问题。仓库中的 `fixes/` 保留了后续修复，包括候选分组、端点保留、节点编号与填充值冲突等问题的处理。另外，部分后期版本曾将历史上已经直接连接的节点纳入候选，并利用未来可达性筛选候选。这与最初的首次新连接预测任务并不完全一致。后续修复主要解决了实现一致性问题，尚未把所有历史版本统一到原始任务定义上。这些问题不否定此前的探索，但意味着不能直接把历史排序分数当成科学发现效果。

### 5.4 暂停是一种时间成本上的选择

继续这个方向，真正需要优先解决的是概念体系、数据清洗与任务定义，而不是再增加一个模型模块。考虑到数据修复和重新训练的成本，我决定暂时将项目搁置，保留代码和实验记录，把精力转向其他研究。我仍然认为原来的问题值得研究，只是目前的数据基础还不足以支撑想要实现的目标。

## 6. 后续方向

如果重新启动项目，我更希望先解决数据来源与概念一致性问题。一个考虑中的方向是使用生物医学文献及其更规范的术语体系，例如 MEDLINE 的 MeSH 标注，并结合必要的概念映射来构建关系网络。相较于直接依赖旧版 OpenAlex Concepts，这可能更有利于控制同义词、歧义和概念层级问题。但这仍然需要实际检查数据，不能预先保证能够解决全部问题。随后再重新明确训练目标：

1. 在历史时点固定概念集合及其已有连接。
2. 只选择当时尚未直接连接的概念对。
3. 使用历史信息构建网络结构、时序及必要的语义特征。
4. 根据未来文献判断哪些候选形成了首次直接联系。
5. 进一步追溯候选关系对应的论文与中间知识，交给研究者或 AI 科学家系统评估科学意义。

对我来说，最终目标仍然不是让模型获得一个漂亮的链接预测分数，而是**从海量文献中找到少量值得人认真研究的潜在科学联系**。
